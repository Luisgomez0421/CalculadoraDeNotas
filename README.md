# 📊 Calculadora de Promedio en Python

## 📌 Descripción

Este programa en Python permite calcular el promedio de tres notas ingresadas por el usuario desde la consola.

Es ideal para principiantes que están aprendiendo a trabajar con:

- Entrada de datos (`input`)
- Conversión de tipos (`float`)
- Operaciones matemáticas
- Impresión de resultados en pantalla

---

## 🛠 Tecnologías utilizadas

- 🐍 Python 3

---

## 🚀 Cómo ejecutar el programa

1. Asegúrate de tener **Python 3** instalado.
2. Guarda el código en un archivo llamado:

```
promedio.py
```

3. Ejecuta el programa desde la terminal o consola:

```
python promedio.py
```

4. Ingresa las tres notas cuando el programa lo solicite.

---

## 💻 Código del programa

```python
print("Hallaremos su promedio de notas")
numero1 = float(input("digite su primer nota"))
numero2 = float(input("digite su segunda nota"))
numero3 = float(input("digite su tercera nota"))

promedio = (numero1 + numero2 + numero3) / 3
print("su promedio es:", promedio)
```

---

## 📖 Ejemplo de uso

```
Hallaremos su promedio de notas
digite su primer nota: 4.0
digite su segunda nota: 3.5
digite su tercera nota: 4.5
su promedio es: 4.0
```
